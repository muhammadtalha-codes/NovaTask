# 🚀 NovaTask

An AI-powered productivity platform that helps students and professionals organize tasks, plan their day, manage deadlines, and boost productivity with an intelligent assistant.

## 🌐 Live Demo

👉 https://novatask-beryl.vercel.app

---

## ✨ Features

### 🤖 AI Assistant
- Natural language task management
- Smart scheduling
- Daily planning
- Priority recommendations
- Productivity guidance

### ✅ Task Management
- Create, edit, and organize tasks
- Priority levels
- Deadlines and due dates
- Progress tracking
- Smart reminders

### 📅 Planning Tools
- Calendar view
- Daily schedules
- Upcoming deadlines
- Productivity analytics
- Notification center

### 🔐 Authentication
- Secure user accounts
- Personalized task management
- Protected dashboards

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Next.js API Routes
- Prisma ORM

### Database
- Neon PostgreSQL

### AI
- Groq API
- Llama 3.3 70B

### Deployment
- Vercel
